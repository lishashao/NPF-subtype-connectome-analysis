# NPF subtype connectome analysis

Code accompanying Endres and Dadyala et al.2026. Analyzes the connectivity of NPF
neuron subtypes (DM, L1, P1, P2) in the FlyWire/Codex adult *Drosophila* brain connectome
(snapshot 783), including up/downstream partner overlap (Venn diagrams, Jaccard/hypergeometric
statistics), neuropil innervation profiles, neurotransmitter composition, and partner-class
composition.

## Contents

- `npf_connectome_analysis.ipynb` — the analysis notebook.
- `*_r_id.csv` — root IDs for each NPF subtype (input).
- `*_in1.csv`, `*_in2.csv`, `*_out1.csv`, `*_out2.csv` — first/second-order partner edge
  tables generated by the notebook (output).
